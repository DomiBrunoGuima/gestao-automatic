# Gestão Automatic

Kanban de clientes, projetos e tarefas que conversa com o Claude Code, o Gmail e o Google Agenda. Todo dia o Claude monta o brief da manhã com as prioridades, a agenda, o que receber, o que pagar e o que está parado.

## Como instalar

Baixe a pasta de um destes jeitos:

- Com git: `git clone https://github.com/DomiBrunoGuima/gestao-automatic.git C:\Automatic\gestao-automatic`
- Sem git: botão verde **Code > Download ZIP** e descompacte em `C:\Automatic\gestao-automatic`

Depois siga o [GUIA-DE-INSTALACAO.md](GUIA-DE-INSTALACAO.md) a partir do passo 2.

> Depois do `/configurar`, a pasta passa a ter dados reais de clientes e valores. Não envie esses dados de volta para um repositório público.
